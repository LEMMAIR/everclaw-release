# Fatima (แอปพลิเคชันบนเดสก์ท็อป)

[English](README.md) | [简体中文](README_zh.md) | [繁體中文](README_zh-TW.md) | [日本語](README_ja.md) | [Deutsch](README_de.md) | [Español](README_es.md) | [العربية](README_ar.md) | [Bahasa Melayu](README_ms.md) | [Bahasa Indonesia](README_id.md) | [ไทย](README_th.md) | [Tiếng Việt](README_vi.md)

Fatima คือพื้นที่ทำงานบนเดสก์ท็อปที่ช่วยให้คุณสามารถรัน ประสานงาน และจัดการทีมเอเจนต์ AI เฉพาะทางให้ทำงานอัตโนมัติได้โดยตรงบนคอมพิวเตอร์ของคุณ

---

## คุณสามารถทำอะไรกับ Fatima ได้บ้าง?

### 👥 สร้างทีม AI ในแบบของคุณเอง
สร้างเอเจนต์เฉพาะทางที่มีบุคลิกภาพ คำแนะนำระบบ และใช้โมเดลที่แตกต่างกัน จัดกลุ่มแชทให้ทำงานร่วมกัน หรือสนทนาตัวต่อตัวกับเอเจนต์แต่ละตัวได้

### 🛡️ ปลอดภัยเรื่องความเป็นส่วนตัวของข้อมูล
Fatima ทำงานบนเครื่องคอมพิวเตอร์ของคุณโดยตรง ประวัติการแชท การตั้งค่า ฐานข้อมูล และรหัส API (API Keys) จะถูกเก็บรักษาไว้อย่างปลอดภัยบนอุปกรณ์ของคุณ และไม่มีทางถูกส่งออกไปยังภายนอก **ไม่มีระบบส่งข้อมูลการใช้งาน (Telemetry) และไม่มีการรายงานข้อมูลใดๆ**

### 🤖 ทำความรู้จักกับ Clotho ผู้ดูแลระบบ AI ของคุณ
Clotho คือเอเจนต์ผู้ดูแลระบบที่ติดตั้งมาในแอปพลิเคชัน สามารถคอยตรวจสอบสถานะของเอเจนต์ตัวอื่น มอบหมายงานแทนคุณ และตอบกลับข้อความทั่วไปโดยอัตโนมัติ (พร้อมระบบป้องกันไม่ให้เอเจนต์คุยกันเองจนวนลูป) โดยจะส่งต่อคำขอที่ซับซ้อนมาให้คุณตัดสินใจโดยตรง

### 📂 คลังความรู้ส่วนตัว
แปลงโฟลเดอร์ในเครื่อง ไฟล์ PDF และเอกสารต่างๆ ให้กลายเป็นคลังความรู้แบบเวกเตอร์ได้ทันที คุณสามารถกำหนดคลังความรู้นี้ให้กับเอเจนต์เฉพาะตัวหรือคนทั้งทีม เพื่อให้พวกเขานำข้อมูลจากเอกสารของคุณมาใช้ประกอบการแชทได้

### 🔌 ขยายฟังก์ชันการใช้งานด้วยปลั๊กอิน
ขยายฟังก์ชันการใช้งานด้วยปลั๊กอินขยายขีดความสามารถของเอเจนต์ได้ง่ายๆ โดยการเชื่อมต่อเซิร์ฟเวอร์ Model Context Protocol (MCP) และปลั๊กอินที่คุณต้องการผ่านทางหน้าการตั้งค่า เพื่อให้เอเจนต์มีเครื่องมืออย่างการค้นหาเว็บหรือการรันโค้ด

### ⏱️ จัดการงานประจำวันให้เป็นไปตามตารางอัตโนมัติ
กำหนดตารางงานเบื้องหลังที่ทำซ้ำเป็นรอบ (cron) เช่น สรุปเนื้อหาจากหน้าเว็บ ติดตามความเคลื่อนไหวของไฟล์ หรือสั่งเริ่มเวิร์กโฟลว์เฉพาะตามช่วงเวลาที่กำหนด

### ⚙️ ใช้งานร่วมกับโมเดล AI ที่คุณชอบ
รองรับการเชื่อมต่อกับผู้ให้บริการคลาวด์ชั้นนำหรือรันแบบออฟไลน์บนเครื่อง:
* **ระบบคลาวด์**: OpenRouter, OpenAI, Anthropic Claude, Gemini, DeepSeek
* **แบบใช้งานในเครื่อง/ออฟไลน์**: Ollama, vLLM หรือจุดเชื่อมต่ออื่นๆ ในเครื่องที่เข้ากันได้กับ OpenAI

## ดาวน์โหลดและเริ่มต้นใช้งาน

ดาวน์โหลดแอปพลิเคชัน Fatima เวอร์ชันล่าสุดสำหรับระบบปฏิบัติการของคุณได้ที่หน้า [Releases](https://github.com/LEMMAIR/fatima-release/releases):
* **macOS (Apple Silicon / ARM64)**: ไฟล์บีบอัด `.zip`
* **macOS (Intel / x64)**: ไฟล์บีบอัด `.zip`
* **Windows (x64)**: ตัวติดตั้งแบบ `.exe`

### การตั้งค่าอย่างรวดเร็ว
1. ดาวน์โหลดแพ็คเกจที่ตรงกับระบบปฏิบัติการของคุณ
2. ติดตั้งและเปิดใช้งานแอปพลิเคชัน **Fatima**
3. ในการเปิดใช้งานครั้งแรก ผู้ดูแลระบบการเริ่มต้นใช้งาน (Clotho) จะคอยแนะนำคุณทีละขั้นตอนในการตั้งค่าโมเดล AI และป้อนรหัสเปิดใช้งานคีย์ต่างๆ
