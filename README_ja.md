# Fatima (デスクトップアプリ)

[English](README.md) | [简体中文](README_zh.md) | [繁體中文](README_zh-TW.md) | [日本語](README_ja.md) | [Deutsch](README_de.md) | [Español](README_es.md) | [العربية](README_ar.md) | [Bahasa Melayu](README_ms.md) | [Bahasa Indonesia](README_id.md) | [ไทย](README_th.md) | [Tiếng Việt](README_vi.md)

Fatima は、AI エージェントチームをPC上で直接実行、調整、自動化するために設計されたデスクトップワークスペースです。

---

## Fatima でできること

### 👥 独自の AI チームを構築
異なるモデル、独自の指示、プロフィール（パーソナリティ）を持つカスタムエージェントを作成できます。共同グループチャットで協力させたり、個別に対話させたりすることが可能です。

### 🛡️ 万全のデータプライバシー
Fatima はローカルPC上で動作します。チャット履歴、設定ファイル、データベース、API キーはすべてお使いのデバイスに安全に保存され、外部に送信されることはありません。**テレメトリ収集なし、データ送信・上報なし。**

### 🤖 AI 管理者「Clotho」のサポート
標準で搭載されている監視エージェント「Clotho（クロト）」が、チームの稼働状況をチェックします。Clotho はあなたの代わりに他のエージェントにタスクを委託したり、日常的なメッセージに代理応答（無限ループ防止機能付き）したりできます。複雑なリクエストはあなたに引き継ぎます。

### 📂 ローカルデータからの知識ベース (RAG)
PC上のフォルダ、PDF、ドキュメントを即座にベクトル知識ベースに変換します。特定の親しいエージェントやチーム全体にデータを割り当てることで、会話中に独自の資料を参照させることができます。

### 🔌 プラグインによる機能拡張
エージェントに強力なスキルを追加しましょう。設定画面から Model Context Protocol (MCP) サーバーやカスタムプラグインを直接接続し、エージェントに「ウェブ検索」や「コードの実行」などの機能を追加できます。

### ⏱️ ルーティンワークの自動化
定期的なバックグラウンドジョブ（cron）をスケジュールして、ウェブサイトの情報の自動取得・要約、ファイルの監視、特定の間隔でのカスタムワークフローのトリガーなどをローカルで自動実行できます。

### ⚙️ お気に入りの AI モデルに対応
クラウドサービスの接続から完全なオフライン稼働まで幅広く対応しています：
* **クラウド**：OpenRouter、OpenAI、Anthropic Claude、Gemini、DeepSeek
* **ローカル/オフライン**：Ollama、vLLM、またはその他の OpenAI 互換ローカルエンドポイント

## ダウンロードとセットアップ

[Releases](https://github.com/LEMMAIR/fatima-release/releases) ページから、お使いの OS に対応した最新の Fatima をダウンロードしてください：
* **macOS (Apple Silicon / ARM64)**: `.zip` アーカイブ
* **macOS (Intel / x64)**: `.zip` アーカイブ
* **Windows (x64)**: `.exe` インストーラー

### クイックスタート
1. お使いのオペレーティングシステムに合ったパッケージをダウンロードします。
2. **Fatima** をインストールして起動します。
3. 初回起動時、オンボーディングアシスタント（Clotho）が好みの AI モデルの設定と API キーの入力手順をわかりやすく案内します。
