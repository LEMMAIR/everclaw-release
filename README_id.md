Fatima adalah ruang kerja desktop yang memungkinkan Anda menjalankan, mengoordinasikan, dan mengotomatiskan tim agen AI khusus secara langsung di komputer Anda.

---

## Apa yang dapat Anda lakukan dengan Fatima?

### 👥 Bangun Tim AI Kustom Anda
Buat agen khusus dengan kepribadian, instruksi sistem, dan model yang berbeda. Atur mereka ke dalam obrolan grup kolaboratif atau berkonsultasilah dengan mereka secara individu.

### 🛡️ Privasi Data Sepenuhnya
Fatima berjalan secara lokal di komputer Anda. Obrolan, pengaturan, basis data, dan kunci API Anda disimpan dengan aman di perangkat Anda dan tidak pernah meninggalkan komputer Anda. **Tanpa telemetri, tanpa pelaporan data.**

### 🤖 Kenalkan Clotho, Supervisor AI Anda
Clotho adalah agen supervisor bawaan Anda. Clotho dapat memantau agen aktif Anda, mendelegasikan tugas atas nama Anda, dan membalas pertanyaan rutin secara otomatis (termasuk perlindungan siklus obrolan) serta meneruskan permintaan yang rumit langsung kepada Anda.

### 📂 Perpustakaan Pengetahuan Pribadi
Ubah folder lokal, file PDF, dan dokumen menjadi basis pengetahuan vektor instan. Tetapkan basis pengetahuan tersebut ke agen tertentu atau seluruh tim agar mereka dapat merujuk file kustom Anda selama obrolan.

### 🔌 Perluas dengan Plugin
Perluas kemampuan agen Anda. Hubungkan server Model Context Protocol (MCP) dan plugin kustom langsung dari pengaturan desktop untuk memberikan alat seperti pencarian web atau eksekusi kode ke agen Anda.

### ⏱️ Otomatiskan Rutinitas Harian
Jadwalkan tugas latar belakang berulang (cron) untuk mengambil dan meringkas konten web, memantau file, atau memicu alur kerja kustom pada interval tertentu.

### ⚙️ Bekerja dengan Model Favorit Anda
Hubungkan ke penyedia cloud utama atau jalankan secara offline sepenuhnya:
* **Cloud**: OpenRouter, OpenAI, Anthropic Claude, Gemini, DeepSeek.
* **Lokal/Offline**: Ollama, vLLM, atau endpoint lokal apa pun yang kompatibel dengan OpenAI.

## Unduhan & Mulai Penggunaan

Dapatkan versi terbaru Fatima untuk platform Anda dari halaman [Releases](https://github.com/LEMMAIR/fatima-release/releases):
* **macOS (Apple Silicon / ARM64)**: Arsip `.zip`
* **macOS (Intel / x64)**: Arsip `.zip`
* **Windows (x64)**: Penginstal `.exe`

### Penyiapan Cepat
1. Unduh paket yang sesuai dengan sistem operasi Anda.
2. Instal dan luncurkan aplikasi **Fatima**.
3. Pada peluncuran pertama, asisten onboarding (Clotho) akan memandu Anda langkah demi langkah untuk menyiapkan model AI pilihan Anda dan memasukkan kredensial Anda.
