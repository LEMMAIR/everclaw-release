Fatima 是一款专为在您的电脑上运行、协同和自动化 AI 智能体团队而设计的桌面工作空间。

---

## Fatima 能为您做什么？

### 👥 打造您的专属 AI 团队
创建具有不同性格、定制指令和模型的专属智能体。您可以将它们加入协作群聊中，或者进行一对一咨询。

### 🛡️ 完美的隐私保护
Fatima 完全在您的本地运行。您的聊天记录、配置、数据库和 API 密钥均安全地保存在本地设备上，绝不会离开您的电脑。**零遥测收集，绝无数据上报。**

### 🤖 认识您的 AI 主管 Clotho
Clotho 是您的内置监督智能体。Clotho 可以监控活跃的智能体状态、代表您委派任务，并在遇到常规咨询时自动回复（内置防无限对话循环保护），同时将复杂的请求自动升级给您亲自处理。

### 📂 专属本地知识库
将本地文件夹、PDF 和文档轻松转化为向量知识库。您可以将其分配给特定智能体或整个团队，以便它们在对话中随时查阅您的自定义文件。

### 🔌 丰富的插件扩展
扩展您的智能体技能。直接在设置中连接 MCP（模型上下文协议）服务器和自定义插件，赋予智能体网页搜索、代码运行等实用工具。

### ⏱️ 日常任务自动化
设置定时后台任务（cron），定期抓取并总结网页内容、监控文件变动，或在特定时间间隔触发自定义工作流。

### ⚙️ 支持您喜爱的任意模型
无论是连接主流云端服务还是完全离线运行，都能轻松搞定：
* **云端**：OpenRouter, OpenAI, Anthropic Claude, Gemini, DeepSeek。
* **本地/离线**：Ollama, vLLM 或任何兼容 OpenAI 规范的本地端点。

## 下载与启动

您可以在 [Releases](https://github.com/LEMMAIR/fatima-release/releases) 页面下载适用于您平台的最新版 Fatima：
* **macOS (Apple Silicon / ARM64)**：`.zip` 压缩包
* **macOS (Intel / x64)**：`.zip` 压缩包
* **Windows (x64)**：`.exe` 安装程序

### 快速上手
1. 下载适合您操作系统和架构的安装包。
2. 安装并启动 **Fatima** 应用。
3. 首次启动时，新手引导助手 Clotho 将一步步带您配置首选的 AI 模型并输入必要的凭据。
