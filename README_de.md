Fatima ist ein Desktop-Arbeitsbereich, mit dem Sie spezialisierte KI-Agententeams direkt auf Ihrem Computer ausführen, koordinieren und automatisieren können.

---

## Was können Sie mit Fatima tun?

### 👥 Ihr eigenes KI-Team aufbauen
Erstellen Sie spezialisierte Agenten mit unterschiedlichen Persönlichkeiten, Anweisungen und Modellen. Organisieren Sie sie in kollaborativen Gruppen-Chats oder sprechen Sie direkt mit ihnen.

### 🛡️ Voller Datenschutz
Fatima läuft lokal auf Ihrem Computer. Ihre Chats, Einstellungen, Datenbanken und API-Schlüssel werden sicher auf Ihrem Gerät gespeichert und verlassen es nie. **Keine Telemetrie, keine Datenübermittlung.**

### 🤖 Lernen Sie Clotho kennen, Ihren KI-Supervisor
Clotho ist Ihr integrierter Supervisor-Agent. Clotho überwacht Ihre aktiven Agenten, delegiert Aufgaben in Ihrem Namen und beantwortet Routineanfragen automatisch (Schleifenschutz inklusive), während komplexe Anfragen direkt an Sie weitergeleitet werden.

### 📂 Lokale Wissensdatenbanken
Verwandeln Sie lokale Ordner, PDFs und Dokumente in Wissensdatenbanken. Weisen Sie diese bestimmten Agenten oder dem gesamten Team zu, damit sie in Chats auf Ihre Dokumente zugreifen können.

### 🔌 Erweiterung durch Plugins
Erweitern Sie die Fähigkeiten Ihrer Agenten. Verbinden Sie Model Context Protocol (MCP)-Server und benutzerdefinierte Plugins direkt über die Einstellungen, um Tools wie Websuche oder Codeausführung freizuschalten.

### ⏱️ Tägliche Routinen automatisieren
Planen Sie wiederkehrende Hintergrundaufgaben (Cron-Jobs), um Webinhalte abzurufen und zusammenzufassen, Dateien zu überwachen oder benutzerdefinierte Workflows in bestimmten Intervallen auszuführen.

### ⚙️ Kompatibel mit Ihren bevorzugten Modellen
Egal ob Cloud-Anbindung oder komplett offline:
* **Cloud**: OpenRouter, OpenAI, Anthropic Claude, Gemini, DeepSeek.
* **Lokal/Offline**: Ollama, vLLM oder jeder OpenAI-kompatible lokale Endpunkt.

## Download & Erste Schritte

Laden Sie die neueste Version von Fatima für Ihr Betriebssystem von der [Releases](https://github.com/LEMMAIR/fatima-release/releases)-Seite herunter:
* **macOS (Apple Silicon / ARM64)**: `.zip`-Archiv
* **macOS (Intel / x64)**: `.zip`-Archiv
* **Windows (x64)**: `.exe`-Installationsprogramm

### Schnellstart
1. Laden Sie das passende Paket für Ihr System herunter.
2. Installieren und starten Sie die Anwendung **Fatima**.
3. Beim ersten Start führt Sie der Onboarding-Assistent (Clotho) Schritt für Schritt durch die Konfiguration Ihrer KI-Modelle und Zugangsdaten.
