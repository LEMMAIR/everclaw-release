Fatima 是一款專為在您的電腦上執行、協同和自動化 AI 智能體團隊而設計的桌面工作空間。

---

## Fatima 能為您做什麼？

### 👥 打造您的專屬 AI 團隊
建立具有不同性格、自訂指令 and 模型的專屬智能體。您可以將它們加入協作群聊中，或者進行一對一諮詢。

### 🛡️ 完美的隱私保護
Fatima 完全在您的本地執行。您的聊天記錄、設定、資料庫和 API 金鑰均安全地儲存在本地裝置上，絕不會離開您的電腦。**零遙測收集，絕無數據上報。**

### 🤖 認識您的 AI 主管 Clotho
Clotho 是您的內建監督智能體。Clotho 可以監控活躍的智能體狀態、代表您委派任務，並在遇到常規諮詢時自動回覆（內建防無限對話循環保護），同時將複雜的請求自動升級給您親自處理。

### 📂 專屬本地知識庫
專屬本地知識庫將本地資料夾、PDF 和文件輕鬆轉化為向量知識庫。您可以將其分配給特定智能體或整個團隊，以便它們在對話中隨時查閱您的自訂檔案。

### 🔌 豐富的外掛程式擴充
擴充您的智能體技能。直接在設定中連接 MCP（模型內容協定）伺服器和自訂外掛程式，賦予智能體網頁搜尋、程式碼執行等實用工具。

### ⏱️ 日常任務自動化
設定排程背景任務（cron），定期抓取並總結網頁內容、監控檔案變動， or 在特定時間間隔觸發自訂工作流。

### ⚙️ 支援您喜愛的任意模型
無論是連接主流雲端服務還是完全離線執行，都能輕鬆搞定：
* **雲端**：OpenRouter, OpenAI, Anthropic Claude, Gemini, DeepSeek。
* **本地/離線**：Ollama, vLLM 或任何相容 OpenAI 規範的本地端點。

## 下載與啟動

您可以在 [Releases](https://github.com/LEMMAIR/fatima-release/releases) 頁面下載適用於您平台的最新版 Fatima：
* **macOS (Apple Silicon / ARM64)**：`.zip` 壓縮檔
* **macOS (Intel / x64)**：`.zip` 壓縮檔
* **Windows (x64)**：`.exe` 安裝程式

### 快速上手
1. 下載適合您作業系統和架構的安裝包。
2. 安裝並啟動 **Fatima** 應用。
3. 首次啟動時，新手引導助手 Clotho 將一步步帶您設定偏好的 AI 模型並輸入必要的憑據。
